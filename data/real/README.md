# Real-data outputs

Final application case: `arabidopsis_baseline_AT1G11560/`.

- `exposure.tsv`: baseline GSE80744 AT1G11560 exposure associations duplicated across FT10/FT16 outcome environments;
- `outcome.tsv`: local FT10/FT16 genotype associations;
- `ld_correlation.tsv`: signed LD correlation for the 48 prespecified QC instruments;
- `environment_correlation_phenotype_proxy.tsv`: sensitivity-only FT10/FT16 phenotype-correlation proxy;
- `metadata.json`: data and limitation contract.

The other real-data result directories are under `results/real/` and contain the executed primary, sensitivity and stratified comparator reports.
