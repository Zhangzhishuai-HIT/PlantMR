# PlantMR 发表前验收清单

本清单区分“工具可以运行”和“研究结果可以投稿”。当前仓库的合成数据只能验证软件流程，不能作为植物生物学证据。

## A. 研究问题与数据

- [ ] 明确一个预先指定的植物生物学问题、暴露、结局和因果方向。
- [ ] 说明物种、品种群体、参考基因组、组织、发育阶段、处理条件、地点/年份和样本量。
- [ ] 暴露QTL和结局GWAS具有清楚的来源、版本、样本组成和表型定义。
- [ ] 说明样本重叠、群体结构、亲缘关系、主成分/混合模型控制和基因组构建版本。
- [ ] LD参考面板与研究群体在物种、群体来源、变异编码和参考组装上可解释地匹配。
- [ ] 至少有独立的外部数据、不同环境、不同群体或功能实验用于验证，不以方法之间的一致性作为独立真值。

## B. 工具变量与MR分析

- [ ] 预先固定工具变量阈值、LD阈值、MAF阈值、F统计量阈值和多重检验规则。
- [ ] 报告每个工具变量的SNP、等位基因、beta、SE、P值、EAF、样本量和保留/剔除原因。
- [ ] 报告解释度R²和工具变量强度；不能只报告P值。
- [ ] 处理弱工具变量、赢家诅咒、样本重叠和方向性错误。
- [ ] 主分析方法在分析前确定；固定IVW、随机IVW、MR-Egger和留一分析作为敏感性分析，而不是事后挑选最有利结果。
- [ ] 对水平多效性、异质性、反向因果和单个强影响工具变量分别诊断。
- [ ] 分析多个环境时，区分简单分层结果和正式的G×E因果模型；报告环境间效应差异和相关结构。
- [ ] 分析多倍体、同源亚基因组、PAV或SV时，明确剂量和变异类别，不能把它们静默转换为普通二等位SNP。

## C. 方法学论文必须增加的模拟

至少覆盖：

- 无因果效应的零模型；
- 已知因果效应的强/弱工具变量；
- 平衡和方向性水平多效性；
- LD和相关工具变量；
- 群体结构/亲缘关系；
- 样本重叠；
- 环境间效应异质性；
- 多倍体剂量或PAV/SV编码（如果论文声称支持）。

每个场景报告：假阳性率、功效、偏差、标准误校准、置信区间覆盖率、工具变量筛选率、运行时间和内存。模拟真值必须与真实数据结果分开保存。

## D. 真实植物数据验证

推荐至少包含：

1. 一个分子暴露到农艺性状的真实案例；
2. 一个多环境或胁迫案例；
3. 一个具有已知功能基因、突变体、转基因或基因编辑证据的案例；
4. 一个独立数据集或留出的环境/群体，用于验证候选关系；
5. 一个负对照或理论上不应有因果关系的配对。

所有候选结果都应保留正结果、负结果和无法判断结果，不能只展示成功案例。

## E. 软件论文交付物

- [ ] Git提交、版本号和变更记录；
- [ ] Conda环境锁定和容器构建记录；
- [ ] 一键运行示例；
- [ ] 完整输入格式和错误提示；
- [ ] 所有方法的单元测试和端到端测试；
- [ ] 合成数据、真实数据来源和下载脚本；
- [ ] 与MRBIGR、SMR/HEIDI、GSMR/GSMR2、TwoSampleMR或等价实现的公平比较；
- [ ] 运行时间、内存和大规模批量分析基准；
- [ ] 结果报告中明确区分association、MR-supported candidate和functional validation。

## F. 论文报告标准

MR论文至少按照 STROBE-MR 清单组织标题、摘要、引言、方法、结果、讨论和其他信息。STROBE-MR包含20个主要项目和30个子项目，覆盖单样本和两样本MR。[1]

方法和结果应同时说明MR的三个核心工具变量假设、工具变量来源、效应等位基因协调、LD处理、样本重叠、群体结构、主分析、敏感性分析和局限性。[1][2]

植物多环境分析不能忽略同一群体在不同环境中的相关性；现有植物多环境GWAS方法已经把环境间相关和效应异质性作为核心问题，因此PlantMR的环境分层结果不能直接称为完整的G×E因果模型。[3]

## 当前结论

PlantMR v1.0已经可以作为软件原型、方法流程和补充分析工具使用，但仅凭仓库中的合成示例不能支撑论文投稿。若要写方法学论文，最需要补的是：植物特有的统计创新、真实作物数据、模拟基准、独立验证和与现有工具的公平比较。

若写应用论文，则重点不是继续堆软件功能，而是围绕一个明确作物问题完成数据、MR、跨环境验证和实验功能证据闭环。
