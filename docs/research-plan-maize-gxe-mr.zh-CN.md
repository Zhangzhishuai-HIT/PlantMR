# 路线A研究计划：玉米环境条件感知MR方法学论文

## 1. 研究主线

暂定题目：

**PlantGxE-MR：面向多环境作物分子性状—农艺性状关系的环境条件感知孟德尔随机化框架**

主问题：

> 同一个分子暴露对作物表型的遗传因果效应，是否随水分环境、组织或发育阶段而改变？现有普通MR把环境间效应简单平均时，是否会掩盖真实的条件性因果关系？

PlantMR v1.0 的 `run-stratified` 只是基线分析。论文方法不能把独立分层结果直接称为正式G×E因果模型。正式方法需要显式估计：

- 每个环境的条件效应 `β_e`；
- 全部环境的总体效应 `β_pool`；
- 环境间效应异质性；
- 暴露和结局摘要统计在共享样本/共享群体下的协方差；
- 水分环境改变因果效应的交互项或随机效应。

## 2. 为什么第一主物种选玉米

已核查的玉米数据具有完整的方法学闭环：224个玉米自交系、WW/WS1/WS2三个水分条件、627个高质量RNA-seq样本、约130万高质量SNP、约30,000个表达性状和环境动态eQTL；研究还已经用普通MR优先筛选过候选基因，并对ABA 8'-hydroxylase候选基因进行了功能验证。[1]

原研究还提供了公开数据回执：

- GSA：CRA000334、CRA002002；
- Genome Variation Map：GVM000048；
- NCBI：PRJNA637522；
- 参考组装：B73 RefGen_v4；
- 原研究MR脚本：论文公开仓库/补充材料。

这些条件使玉米比当前核查到的大豆候选资源更适合先做“方法复现→方法改进→独立验证”。大豆保留为第二物种或外部可迁移性验证，不作为第一主线。

## 3. 数据层设计

### 3.1 主数据

- 暴露：同一玉米群体、同一组织/阶段下的表达性状eQTL；
- 结局：同一群体或外部匹配群体的干旱耐受、相对叶含水量、生物量、水分利用效率或农艺性状GWAS；
- 环境：WW、WS1、WS2；
- 变异：统一到B73 RefGen_v4，保留SNP、等位基因、EAF、beta、SE、P值和样本量；
- LD：使用玉米群体匹配的参考面板，不能使用人类LD面板；
- 元数据：样本ID、环境、组织、发育阶段、批次、处理持续时间和表型定义。

### 3.2 外部验证层

至少准备一个不参与方法开发的验证层：

- 另一玉米群体或独立环境；
- 同一候选基因的已发表突变体/转基因/编辑证据；
- 或独立的多环境GWAS/蛋白QTL/代谢QTL数据。

不能把主数据中的普通MR结果当作独立验证。

## 4. 方法学创新

### 4.1 基线

PlantMR v1.0 提供：

- Wald ratio；
- 固定效应IVW；
- 随机效应IVW；
- MR-Egger；
- 异质性Q；
- 留一分析；
- LD clumping；
- 按环境独立运行。

这些是公平基线，不是论文创新本身。

### 4.2 目标方法

PlantGxE-MR 采用多环境摘要数据模型，核心是：

1. 先在每个环境估计SNP—暴露和SNP—结局效应；
2. 用匹配群体和共享样本信息估计环境间摘要统计相关性；
3. 在相关环境效应上拟合总体效应和环境异质性；
4. 同时输出每个环境的效应、总体效应、异质性、方向一致性和预测区间；
5. 在工具变量水平保留LD和水平多效性诊断；
6. 对共享环境样本、不同样本和样本不重叠三种情形分别处理。

输出不使用单一“因果分数”，而使用证据层级：

- stable MR-supported：跨环境方向一致且敏感性通过；
- context-dependent MR-supported：环境效应显著异质；
- weak/inconclusive：工具变量弱、异质性过大或证据不足；
- invalid/unsupported：等位基因、LD、群体或方向性检查失败。

## 5. 公平对照

至少包括：

1. PlantMR v1.0 独立分层MR；
2. 普通 pooled IVW；
3. 固定/随机效应摘要Meta-MR；
4. MR-Egger、weighted median和弱工具变量稳健方法；
5. SMR/HEIDI或GSMR（适合的分子QTL设计）；
6. MRBIGR的原始植物工作流；
7. 植物多环境GWAS/meta-GWAS基线，如metaGE/MTMM，但明确这些不是MR方法。[2]

所有对照必须使用相同的：

- 输入SNP集合；
- 参考组装；
- LD参考；
- 环境划分；
- P值和多重校正；
- 结果筛选规则；
- 训练/开发/验证边界。

## 6. 模拟设计

模拟必须使用植物现实参数，而不是只用人类默认参数：

- 玉米LD衰减和群体结构；
- MAF分布和小样本工具变量；
- 环境间相关；
- 暴露和结局样本重叠；
- 平衡/方向性水平多效性；
- 真实无效工具变量比例；
- 稳定效应、环境特异效应和符号翻转效应。

每个场景报告：

- 类型I错误率；
- 功效；
- beta偏差；
- SE校准；
- 95%置信区间覆盖率；
- 异质性检出率；
- 方向性判定准确率；
- 运行时间和峰值内存。

## 7. 真实数据分析顺序

### Phase 0：数据治理

- 固定原始数据回执、下载日期、文件哈希和参考组装；
- 核对样本ID、环境、组织、阶段和基因型一致性；
- 生成可重跑的manifest；
- 不把原论文结果直接当作真值。

### Phase 1：原研究复现

- 复现关键eQTL/GWAS摘要统计；
- 复现原研究普通MR候选关系；
- 与原论文表格、候选基因和显著性方向逐项核对；
- 记录不能复现的条目，不静默修正。

### Phase 2：方法开发

- 只使用预先划定的开发环境/性状；
- 冻结模型、阈值和停止标准；
- 不能根据最终验证结果回调参数。

### Phase 3：独立验证

- 使用留出的环境、群体或性状；
- 与功能基因/突变体/转基因资料核对；
- 保留阴性结果和不确定结果。

### Phase 4：论文封装

论文主图建议：

1. 数据和PlantGxE-MR工作流；
2. 模拟中的类型I错误、功效、偏差和覆盖率；
3. 方法与基线的运行时间/内存；
4. 玉米WW/WS1/WS2条件性效应和异质性；
5. 关键候选基因的区域图、共定位/功能证据和独立验证；
6. 失败案例、阴性对照和敏感性分析。

## 8. 继续/停止标准

继续方法开发的条件：

- 零模型下类型I错误可接受；
- 在弱工具变量和LD场景下不产生明显虚假优势；
- 在环境异质性场景中优于简单分层IVW；
- 独立玉米数据中方向和候选排序具有可重复性；
- 至少一个候选关系有独立功能或遗传证据支持。

停止盲目扩展的条件：

- 没有可访问的匹配暴露/结局数据；
- 样本ID或环境信息无法恢复；
- 独立验证集不存在；
- 新方法只是在模拟中优于明显不公平的基线；
- 主结果完全依赖一个弱工具变量或一个环境。

## 9. 发表标准

全文按STROBE-MR组织，报告工具变量、三项IV假设、LD、样本重叠、群体结构、主分析、敏感性分析和所有重要阴性结果。[3][4]

当前PlantMR v1.0是可运行的工具底座和基线实现。它还不是方法学论文的最终统计模型；正式投稿前必须完成上述模拟、真实玉米复现、独立验证和公平基线比较。
